# Phase II — WORK IN PROGRESS

Scientific question: **Can a BH/NS classifier trained on RXTE/PCA generalize to completely unseen physical systems observed by NuSTAR?**

| Gate | Status |
|---|---|
| X0 | PASS |
| X1 | PASS |

| Cross-mission classification | NOT YET TESTED |

The candidate census has 11 securely classified BH and 31 securely classified NS systems before final quality screening. Pilot observations 10601308002 (LMC X-3) and 30363002002 (4U 0614+09) have complete source/background/response products for FPMA and FPMB. That is an acquisition/reduction milestone, not a classifier result.

Initial response-aware 5–25 keV representations have been generated experimentally, but continuum-fit and module-consistency limitations remain. X2 has not passed; no measurement freeze exists. No transfer performance estimate may be inferred from these pilots. Phase II is intended as a separate future paper.

Switch to `phase2-nustar` for the cleaned active code, manifests, protocols, reports and tests. Main contains this status documentation only. Software contract tests and prospective folds do not constitute X3 or a scientific ML run.
