# Phase-I journal-neutral manuscript

`main.tex`, `references.bib`, `main.pdf`, the six main figure PDFs, `supplement/supplement.tex` and supporting files are copied from the canonical reviewed Phase-I package. The active source uses the standard 10-point, two-column `article` class on A4 paper, 0.75-inch top/bottom and 0.7-inch side margins, a 0.25-inch column gap, plain page numbers, and `natbib` superscript numerical citations (`numbers,super,sort&compress`) with the standard `unsrtnat` bibliography style. The title and main abstract span both columns; numbered references follow first-citation order separately in each document. Scientific prose, values, citation keys and the bibliography database remain unchanged by the formatting migration; author-approved presentation revisions and three prior audit wording corrections are recorded in `../docs/release_provenance.csv`. Phase II remains a separate future paper. The later local future-work review copy was not silently substituted.

Compile from the release root with `bash manuscript/build.sh`. It works in `build/manuscript/` and leaves tracked sources and PDFs untouched. A TeX installation must provide pdfLaTeX, BibTeX, the standard article class and unsrtnat style, geometry, fontenc, newtxtext/newtxmath, graphicx, amsmath, booktabs, balance, titlesec, xurl, microtype, natbib and hyperref. The build clears generated citation auxiliary files before compiling and records its TeX inputs in `.fls` files. Supplement compilation uses the build directory as working directory because its figure references start with `supplement/`.

The former `mnras.cls` and `mnras.bst` files remain unchanged solely as unused historical artifacts with their original notices and provenance. Neither active source nor the official build depends on them. MNRAS journal names and publisher URLs in scholarly references are bibliographic content and remain intact.

This neutral source is intended for later adaptation to the selected journal's submission template if required. No new target journal is selected, and compatibility with every journal is not claimed.

The standalone supplement retains its linked machine-readable tables and evidence index. Some values duplicate operational files in data/results so the supplement can stand alone; no second manuscript version is included. Original workspace paths in its evidence index are historical references, not all present files. Author names/order, affiliations, funding, disclosures, license and public archive/DOI metadata remain author decisions. The presence of a compiled PDF is not a claim of submission or acceptance.
